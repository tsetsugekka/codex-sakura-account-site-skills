# さくらのサイト制作・運用スキル集

新しいページの作成から、既存ページの軽量化、データ保存、認証、公開まで。実際の制作・運用で得た経験を、特定サイトの情報を含まない再利用可能な手順にまとめた Codex 向けの10スキルです。

![Codex](https://img.shields.io/badge/Codex-スキル集-4f46e5) ![Sakura](https://img.shields.io/badge/さくら-レンタルサーバー-22c55e)

完成済みのサイト雛形や一括実行プログラムではありません。Codex が対象プロジェクトの仕様と実装を読み、必要な手順を選んで作業します。さくら固有の接続・メール設定と、他の小規模サイトにも使える制作・運用の考え方を分けています。

## 何から使うか

| やりたいこと | 最初に使うスキル |
| --- | --- |
| 既存サイトに新しいページを追加する | [新ページ作成](skills/new-page-creation-guide/SKILL.md) |
| ページが重い。まず原因や改善価値を知りたい | [読み込みの軽量化](skills/web-performance-slimming/SKILL.md) |
| 検索本文や共有カードを確認したい | [SEO・共有表示](skills/public-page-seo-assist/SKILL.md) |
| 公開したのに古い画面が出る | [公開後の更新確認](skills/static-deploy-refresh-check/SKILL.md) |
| 履歴・キャッシュ・ログが増え続ける | [データ増加の監査](skills/data-growth-guard/SKILL.md) |
| 定時収集を安全に運用したい | [定時収集の運用](skills/cron-crawler-safety/SKILL.md) |
| サイトの接続・メール・会員機能を用意したい | 下の「基盤を整える」から選択 |

新ページ作成は入口役です。本文、共通のメニュー・ヘッダー・フッター、読み込み、保存、公開を確認し、必要な専門スキルだけを組み合わせます。既存ページを直すときは、各スキルを単独で使えます。新ページを作るために旧ページや既存の記事生成器を一括改造することはありません。

## 収録スキル

### ページを作る・改善する

| スキル名 | 担当すること |
| --- | --- |
| `new-page-creation-guide` | プロジェクトの共通部品と規約を使い、新しいページの構成と確認手順を選ぶ |
| `web-performance-slimming` | 初回と滞在中の転送量を測り、圧縮・重複取得・必要範囲の読み込みを改善する |
| `public-page-seo-assist` | 初期本文、検索用メタ情報、正規 URL、共有カードを確認する |
| `static-deploy-refresh-check` | 配布順序、古い資産参照、サーバー生成データの保護、公開後の更新を確認する |
| `data-growth-guard` | 無制限な増加を観測し、原本・公開用データ・キャッシュ・保存期間を整理する |
| `cron-crawler-safety` | 定時処理の時刻、アクセス間隔、排他制御、検証、失敗通知を整える |

### 基盤を整える

| スキル名 | 担当すること |
| --- | --- |
| [`sakura-ssh-deploy-setup`](skills/sakura-ssh-deploy-setup/SKILL.md) | 秘密情報を公開せず SSH/SFTP 接続と許可ファイルだけの配布を準備する |
| [`sakura-mailbox-setup`](skills/sakura-mailbox-setup/SKILL.md) | 送信元メールボックス、DNS、送信設定と配送確認を行う |
| [`sakura-auth-site-setup`](skills/sakura-auth-site-setup/SKILL.md) | 登録、メール確認、パスワード再設定、セッションとページ/API 権限を構築する |
| [`sakura-api-secrets-deploy`](skills/sakura-api-secrets-deploy/SKILL.md) | API キー等の非公開保存、共通読み取り、移行とアクセス制御を整える |

既存の基盤は再利用します。メール送信環境の準備と登録認証の実装、ページの表示制御と API の権限確認は、それぞれ別の仕事です。

## 依頼例

**新しいページを追加する**

```text
$new-page-creation-guide を使って、公開の分析ページを追加してください。
既存のメニュー、ヘッダー、フッターを再利用し、検索対象の本文と
動的な図表を分けてください。旧ページと既存の自動生成処理は変更しません。
```

**まず軽量化の価値だけ調べる**

```text
$web-performance-slimming で、このページの初回読み込みと繰り返し取得を
調べてください。gzip が実際に使われているかも確認し、今回は評価だけにしてください。
```

**既存の定時処理を直す**

```text
$cron-crawler-safety を使って、今の実行時刻とデータの意味を変えずに、
余分な起動、重複実行、失敗時の扱いを確認してください。
```

**保存領域を整理する**

```text
$data-growth-guard で、履歴・キャッシュ・バックアップの役割と増加を調べてください。
旧名の残存と復元価値のある資料を分け、削除せず候補と根拠を示してください。
```

## 導入と構成

必要な `skills/<スキル名>/` フォルダーを、使用する Codex のスキル配置先へ入れます。たとえばユーザー用の `~/.codex/skills/` です。同名の導入済みスキルがある場合は、差分とローカル設定を確認してから更新してください。

新ページ作成から専門スキルも使う場合は、対象のフォルダーも一緒に導入します。導入していないスキルが自動で取得・実行される仕組みではありません。

```text
skills/
  <スキル名>/
    SKILL.md          作業の入口と判断基準
    agents/           表示名と依頼例
    references/       必要な場合だけ読む詳細
    scripts/          同梱されている場合の補助ツール
```

補助ツールには Python 3、SSH/SFTP、Expect、シェル等が必要です。使うスキルの説明で条件を確認してください。接続情報や本番データは同梱していません。GitHub の作成・公開には別途 `github-repo-publish-setup` を使用します。自動テストの成功は本番公開や検索収録の保証ではありません。

## 運用上の境界

- 実例は匿名化し、対象サイト自身の仕様、権限、保存期間と配布手順を優先します。未検証の案を運用実績として追加しません。
- 評価だけの依頼でファイルを削除したり、本番設定を変えたりしません。
- 画面や詳細情報を削って軽量化せず、圧縮率と実際の表示速度を分けて確認します。
- 本番の生成データを古いローカルコピーで上書きせず、秘密情報・個人情報・ログを公開物に含めません。
- 外部サイトのアクセス制限を独断で回避しません。公開・削除・外部送信は依頼された範囲で行います。

本スキル集は、さくらインターネットの公式製品ではありません。サーバーの契約と実行環境に合わせて確認してください。
